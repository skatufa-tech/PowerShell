# PowerShell Automation for Windows, Intune & Endpoint Management

A collection of practical PowerShell scripts for Windows administration, Microsoft Intune application deployment, Microsoft Defender updates, and endpoint management.

Collection of scripts from [TechEUC - Intune & SCCM Guides](https://techeuc.com)

This repository is maintained by **Skatufa Tech** and is intended to help IT administrators, endpoint engineers, and system administrators automate common Windows management tasks.

## What's Included

### 1. Microsoft Defender Client Update
Scripts and supporting resources for managing Microsoft Defender client platform updates.

- Review the script and prerequisites before execution.
- Validate the update process in a test environment.
- Review the available logging and error-handling behavior before production use.

### 2. ZeeDrive Installation
PowerShell resources for deploying or managing ZeeDrive in managed Windows environments.

- Review the installation and deployment configuration.
- Adapt the script to your environment and management platform.
- Test installation, detection, and execution behavior before broad deployment.

## Intended Use Cases

These scripts may be useful for:

- Microsoft Intune Win32 application deployment
- Windows endpoint administration
- PowerShell automation
- Microsoft Defender management
- Application installation and troubleshooting
- Managed endpoint environments

## Getting Started

1. Browse the relevant project folder.
2. Read the script and any accompanying documentation.
3. Confirm the prerequisites, execution context, and configuration values.
4. Test in a non-production environment.
5. Validate the outcome and review any generated logs before deploying more broadly.

Run scripts only after reviewing their contents and understanding their impact. Adapt execution policies, permissions, paths, and application-specific settings to your environment.
